# Sources and project references

## Challenge documents supplied with the project

1. `Planetary_Propulsion.HackathonParticipantGuide (1).pdf` — supplied participant guide. OCTO-EARTH’s crosswalk in `frontend/physics_guide.html` summarizes the 10 numerical benchmarks, judging weights, schedule and report/video limits, and structural-safety floor. Reviewed 27 October 2026.
2. `TF'26 PROBLEM STATEMENTS.pdf` — supplied problem statements, including the Octo-Earth brief on pp. 42–43. Reviewed 27 October 2026.

The reviewed copies do not contain the separate rulebook’s requested numeric limits for Earth rotation-axis tilt or eccentricity change. No such values are invented in this package. They also do not provide project-specific hardware tolerances or certify a design.

## Project-local sources of truth

- `octoearth_rl.py` — all Python orbital/RL/simulation logic, `ENABLERS`, checks and configuration.
- `failed_models.py` and `frontend/failedPhysics.js` — the four failed-model calculations (including the 10 km/s Earth-derived thruster case); Python/JavaScript parity is tested.
- `README.md` and `RL_CODE_GUIDE.md` — setup, physics, model architecture and limitations.
- `frontend/physics_guide.html` — requirements crosswalk, benchmark results, threshold caveat and judging requirements.
- `CALCULATIONS_REPORT.pdf` / `.html` — calculations generated by calling the same functions as the simulation; current package copy is regenerated 27 October 2026.
- `example_results/current_checks.json`, `physics_checks.json`, `guide_benchmarks.json` — dated project result snapshots from the earlier successful check, not p40 evidence. The current p40 verification limits are summarized in `VALIDATION_AND_OPEN_GAPS.md`. The archived `example_results/comparison.json` is explicitly pre-hold and is not current PPO evidence.

All numerical figures in this package are either project-local model outputs or values quoted in the supplied challenge guide; they are not independent engineering verification. “High-fidelity” names the project’s N-body integrator relative to its fast training model, not real-world fidelity.
